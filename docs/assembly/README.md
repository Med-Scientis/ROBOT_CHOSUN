# 팔꿈치 로봇 설계 파일

[11월 21일 출력 묶음과 조립 순서](forearm_fit/조립과_견적.md)에서 최신 STL 9종의 수량과 용도를 확인한다. 견적에는 이 문서가 연결한 ZIP을 사용한다. STEP은 설계 검토용이다.

[11월 20일 풀리·모터판 설계](joint_drive/설계검토.md)와 이 폴더의 시편은 이전 설계 단계의 기록이다. 모터 장착부 비교 스크립트를 다시 실행할 때는 사용 중인 DM4340P의 공급사 CAD 원본을 이 폴더 아래 `references/DM4340P.step`에 둔다. 배포된 출력 파일과 수량표는 CAD 프로그램 없이 사용할 수 있다.
