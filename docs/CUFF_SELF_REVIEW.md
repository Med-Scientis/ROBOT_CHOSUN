# 팔 받침·찍찍이 설계 자체 검토

검토일: 2026-11-18. 대상: `6895f7276012364722f009b3bee0c12c73b253bf`의 팔 받침안과 프레임·관절안.

**결론: 기존 치수 그대로 제작할 단계가 아니다.** 아래팔의 굵기 변화와 프레임 연결 높이를 함께 풀지 않았고, 찍찍이 루프 150mm를 네 곳에 공통 적용한 제안은 작은 받침의 경로에 맞지 않는다. 기존 파일 판독·치수 검사는 조립 적합 검사가 아니었다. 이 두 누락은 이전 설계 작성 과정에서 놓친 부분이다.

사용자 결정인 상완 모터 → 벨트 → 독립 관절축 → 전완 프레임 구조, 모터 중심 147.5mm, 찍찍이로 팔 굵기를 맞추는 방식은 유지한다. 사용자 팔 길이·둘레와 종이 모형에서 불편 없었다는 보고도 그대로 보존한다.

| 우선순위 | 발견 사항 | 현재 조치 |
|---|---|---|
| 높음 | 아래팔 두 받침과 곧은 프레임의 연결 높이가 미해결 | 블록 중앙 3mm 공통 적용을 철회. 관절 연결면과 함께 높이·각도를 결정 |
| 높음 | 모터·벨트·관절·커프가 하나의 입체 좌표로 연결되지 않음 | 가공·봉제 확정 보류. 공통 조립 좌표와 움직임 범위 검토를 다음 작업으로 지정 |
| 중간 | 손목 쪽 루프 패치 150mm가 단순 경로보다 김 | 네 곳 공통 완성 길이를 철회. 위치별 경로·필요 겹침·조절 범위로 결정 |
| 높음 — 검증 공백 | 볼트 머리 위 잔여 패드 2mm와 체결 강도에 근거 부족 | 2mm를 설계 기준에서 제거. 체결 구조와 실제 패드 눌림·하중 검증 필요 |

## 1. 아래팔이 가늘어지는 만큼 프레임 연결 높이도 달라진다

기존안은 팔꿈치에서 70mm인 위치에 안쪽 반지름 43mm, 180mm인 위치에 32mm 받침을 사용한다. 두 곳 모두 금속 2mm와 중앙 3mm 블록을 더하면, **같은 곧은 팔 중심선을 가정한 프레임 안쪽 면의 거리**는 다음과 같다.

| 위치 | 받침 안쪽 R | 금속 바깥 R | 3mm 블록 뒤 프레임 면 |
|---|---:|---:|---:|
| 아래팔 팔꿈치 쪽 F23 | 43 | 45 | 48 |
| 아래팔 손목 쪽 F16 | 32 | 34 | 37 |

두 면의 높이 차는 **11mm**, 길이 방향 간격은 **110mm**다. 팔 중심선과 평행한 곧은 프레임을 두 곳에 붙이려면 이 차이를 연결부에서 보정해야 한다. 프레임을 약 `atan(11/110) = 5.71°` 기울여 잇는 방법도 있지만, 그 경우 접촉면 각도와 관절 연결부도 바뀐다. 원래의 평평한 3mm 블록 두 개를 그대로 쓰면 된다고 설명할 수 없다.

예를 들어 평행 프레임을 선택하고 팔꿈치 쪽 블록 3mm를 유지하면 손목 쪽은 계산상 중앙 14mm가 필요하다. **14mm는 가정 아래의 설명용 값이며 새 제작 치수로 확정하지 않는다.** 실제 팔 단면의 중심 이동, 관절 허브의 위치, 프레임 단차를 함께 정해야 한다.

받침 자체도 확인이 필요하다. 두 둘레를 원형으로 보고 선형으로 가늘어진다고 가정하면, 폭 45mm에 걸친 반지름 변화는 `(230−160)/(2π) ×45/110 ≈ 4.56mm`다. 기존 받침은 길이 방향으로 반지름이 일정한 원통형이므로 넓은 쪽 끝과 좁은 쪽 끝이 다르게 닿을 수 있다. 이 값은 실제 국부 형상·압력 측정이 아니다. 단면을 맞춘 뒤 테이퍼형 또는 다른 접촉 형상으로 보정해야 하며, 형상이 바뀌면 기존 직사각 전개도도 다시 작성한다.

## 2. 찍찍이의 재료 준비 길이와 붙일 수 있는 길이는 다르다

초벌 웨빙 450/400/350mm는 길게 준비한 재료량으로 유지할 수 있다. 문제는 **루프 패치 완성 길이 150mm를 모든 위치에 공통 적용**한 부분이다.

팔을 원형, 패드를 눌리지 않은 6mm, 끈을 두께 없는 선으로 가정했다. 120° 받침의 양 끝 직선부에서 슬롯 중심을 잡고, 열린 쪽 패드 원에 닿는 두 접선과 원호를 합하면 아래 경로가 나온다. 슬롯 가장자리의 꺾임·봉제부·실제 눌림은 제외한 검토 계산이다.

| 받침 | 슬롯 사이 주 경로 근사 | 기존 루프 제안 | 판단 |
|---|---:|---:|---|
| U31 | 약 214mm | 150mm | 길이 공간은 있으나 실제 봉제·조절 범위 확인 필요 |
| F23 | 약 161mm | 150mm | 슬롯·고정부 여유가 작아 실제 배치 재검토 |
| F16 | 약 115mm | 150mm | 패치가 주 경로보다 약 35mm 길어 공통 배치를 적용할 수 없음 |

계산식: `r=C/(2π)+6`, `n=받침R+1`, `x=−n cos60°+10 sin60°`, `y=n sin60°+10 cos60°`, `d=√(x²+y²)`. 열린 쪽 접촉각을 `θ=atan2(y,x)−acos(r/d)`로 두면 `경로=2√(d²−r²)+2rθ`다. [재현 계산](cuff/check_self_review.py)과 [결과 JSON](cuff/SELF_REVIEW_CALCULATIONS.json)에 입력과 한계를 기록했다. 원호를 작은 직선 2,000개로 나눈 계산과도 0.001mm 이내로 일치한다. 이 수치 정밀도는 실물 치수의 정밀도를 뜻하지 않는다.

최종 루프 길이는 `사용 가능한 주 경로 − 슬롯/봉제 여유` 안에 들어가야 하고, 동시에 필요한 훅 겹침과 원하는 둘레 조절 범위를 확보해야 한다. **작은 받침을 맞추려고 겹침부터 임의로 줄이지 않는다.** 조건을 충족하지 못하면 슬롯 위치·되접는 방식·끈 경로를 바꾼다. 기존 80mm 겹침은 강도 시험을 거친 최소치가 아니다. 훅·루프는 힘을 받는 방향과 제품에 따라 성능이 달라진다. ## 3. 옆으로 얼마나 튀어나오는지 아직 결정되지 않았다

[관절안](FRAME_JOINT_DRAFT_2026-11-16.md)은 베어링 A 안쪽 면을 z=0으로 삼고, 관절 풀리 예약 구간을 10~38mm, 아래팔 허브를 50~70mm에 둔다. 이 기준면은 피부면·모터 장착면·커프 연결면과 연결되지 않았다. 따라서 조립 공간의 합이 맞아도 모든 부품이 맞물린다는 뜻은 아니다.

다음 입체 배치에서 최소한 아래 값을 같은 좌표로 표시해야 한다.

- 모터 장착면과 출력면, 직접 체결 출력 풀리의 실제 벨트 중심면
- 관절 베어링 A 기준면과 관절 풀리의 실제 벨트 중심면: 현재 예약 구간의 중앙은 24mm지만 실제 풀리 형상으로 확정 필요
- 아래팔 허브의 프레임 체결면, 두 아래팔 받침의 접촉면과 연결 높이
- 모터판·패드·볼트 끝·벨트 덮개·각도 센서가 차지하는 범위와 굽힘 중 간섭

두 풀리의 축이 평행하고 벨트 중심면이 일치하는지, 아래팔 프레임이 허브와 커프 사이에서 무리 없이 이어지는지 확인한다. **실제로 충돌한다고 확정한 것은 아니며, 충돌하지 않는다는 근거가 아직 없는 상태다.** 모터의 길이 방향 위치 147.5mm를 바꾸기 전에 옆 방향 체결 배치를 먼저 해결한다.

## 4. 볼트 위에 패드 2mm만 남기는 값을 기준으로 쓰지 않는다

기존안은 6mm 패드 뒷면에 볼트 머리·분산판 홈을 파고 피부 쪽에 최소 2mm를 남기도록 제안했다. 실제 제품의 눌림과 반복 하중, 국부 압박을 확인하지 않은 수치여서 **충분한 두께로 취급할 근거가 없다.** 이번 개정에서는 이 숫자를 기본값에서 제거한다.

피부 쪽 단단한 돌출을 줄이는 체결 구조와 하중 분산을 우선 검토한다. 안쪽 머리를 유지한다면 실제 머리/판 높이와 눌린 패드 두께, 미끄러짐·압박을 검증해야 한다. 볼트 두 개·구멍 간격 14mm·2mm 알루미늄이라는 명목 치수만으로 강도를 판정하지 않는다. 받침/슬롯 변형, 블록의 눌림과 크리프, 봉제와 훅·루프 유지력, 풀림도 시험 대상이다.

## 이번에 바로잡은 것과 남은 것

- 공통 3mm 블록, 공통 150mm 루프 완성 길이, 잔여 패드 2mm 기준을 철회하고 미정 항목으로 표시했다.
- 기존 SVG와 DXF에 자체 검토 후 **가공 보류** 표시를 넣었다. DXF의 절단/성형 참고 형상은 보존했으며, 보정이 끝난 가공 도면으로 바꿨다는 뜻이 아니다.
- JSON에 과거 제안과 미확정 제작값을 구분했다. 기준 문서와 팀원 안내에 결과를 연결했다.
- 치수·경로 계산을 재현했다. 실물 맞춤·강도·피부 압박·동력·예산 적합 시험을 완료한 것은 아니다. 남은 예산 283,033원에는 기구 외 배선·보호·배송도 들어가며 실제 기구 견적은 없다.

**다음 작업은 공통 좌표의 입체 조립 배치 → 받침/블록/끈 경로 보정 → 전원 없는 모형 대조 → 가공 도면·견적 확정이다.** 하중 검증은 시험대·더미팔부터 진행한다. 자체 검토 완료와 설계 수정·제작 검증 완료를 구별한다.
