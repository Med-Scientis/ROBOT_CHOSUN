# ROBOT_CHOSUN

**Second Muscle**은 위팔 모터가 벨트와 팔꿈치 축을 돌려 팔 굽힘을 돕는 공모전용 로봇이다.

## 착용형 시제품 도면 · 2026년 11월 25일

[전체 출력 목록과 부품 그림](docs/assembly/wearable_joint/3D출력_검토.md) · [최신 전체 조립도(STEP)](docs/assembly/wearable_joint/bearing_seats/ELBOW_BEARING_SEATS_ASSEMBLY_REVIEW.step) · [모터 실물 대조표(A4)](docs/assembly/wearable_joint/DM4340P_실물대조_A4.pdf)

팔 한쪽의 기구를 모두 출력 모형으로 만들면 **16종 34개**다. 팔 받침은 가운데 받침 4개와 찍찍이 끈을 따라 움직이는 조각 18개로 구성한다. 팔꿈치 양쪽 베어링 받침과 벨트 아래 케이스도 수정했다. [분할 팔 받침 조립](docs/assembly/wearable_joint/segmented_cuffs/팔받침_조립.md) · [베어링 조립과 수정 부품 4개](docs/assembly/wearable_joint/bearing_seats/베어링_자리_조립.md)

**모터를 받으면** A4 대조표를 100%로 인쇄하고 배터리를 분리한 채 뒤쪽 나사 4곳, 앞쪽 회전면 6곳, 동봉 플러그가 케이스 기둥을 지나는 자리를 확인한다. 도면상의 맞춤을 확인한 단계이며, 실제 수령품과의 대조, 출력 견적, 모형 팔의 하중·정지 시험이 남았다.
