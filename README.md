1. [PROJECT_STATE.md](PROJECT_STATE.md) — 최신 확정 사항, 우선 검토 후보, 미확정 사항, 예산, 설계 순서, 안전·검증 조건과 결정 이력 (**설계 기준 문서**)
2. [FRIEND.md](FRIEND.md) — 처음 함께 만드는 팀원을 위한 구조·배선·구매·시험 안내
3. [업체별 구매표 엑셀](docs/purchase/Second_Muscle_Purchase_2026-11-07.xlsx) — 11월 7일 계획액과 지원금 확인을 반영한 구매표
4. [AGENTS.md](AGENTS.md) — ChatGPT / Codex 작업 전 반드시 지킬 규칙

현재 채택된 동력 전달 구조: **상완 모터 → 타이밍벨트 → 독립 베어링 팔꿈치 관절축 → 전완 프레임**.

모터 **AK45-36 V3.0 KV80**과 **HTD5M 36T/36T (1:1)**은 현재 우선 검토안이며, 구입 및 상세 설계 확정은 아직 아니다.

11월 10일 정리한 착용 방식은 **위팔·아래팔을 찍찍이 끈으로 감아 팔 굵기에 맞추는 방식**이다. 11월 12일 위팔 260mm·아래팔 250mm를 받아 [배치도 초안](docs/ARM_LAYOUT_2026-11-12.svg)에 반영했다. 11월 16일 모터 중심을 팔꿈치 축에서 어깨 방향 **147.5mm**에 두는 위치를 설계 기준으로 채택했다. 이 배치에 맞춘 [프레임·관절 1차 설계안](docs/FRAME_JOINT_DRAFT_2026-11-16.md)과 [A4 배치 확인용 종이 본](docs/FRAME_FIT_TEMPLATES_2026-11-16.pdf)을 작성했다. 새 축·베어링·프레임 치수는 검토 제안이며, 실물 대조·입체 배치·상세 가공 도면·강도 검증은 남아 있다. DOGCOM 기준 구매계획 소계는 490,967원이며 가공·추가 배선·보호부품·배송 등의 견적이 남아 있다.

11월 17일 [팔 받침·패드·찍찍이 상세 검토안](docs/CUFF_STRAP_DESIGN_2026-11-17.md)을 추가했다. 사용자 제공 둘레와 종이 모형의 걸림·불편 없음 보고를 반영했으며, 연결 그림·받침 전개 DXF 3종·치수표·견적 묶음이 포함된다. 파일과 치수 계산을 확인한 **검토 자료**이며 최종 가공 승인·하중 시험을 완료한 도면은 아니다.

> 변경 후에는 `PROJECT_STATE.md`와 결정 이력을 갱신한다. 이 문서가 자동으로 새 채팅에 주입된다고 가정하지 말고 작업 전 GitHub의 최신 파일을 직접 확인한다.
