모터 **AK45-36 V3.0 KV80**과 **HTD5M 36T/36T (1:1)**은 현재 우선 검토안이며, 구입 및 상세 설계 확정은 아직 아니다.

11월 10일 정리한 착용 방식은 **위팔·아래팔을 찍찍이 끈으로 감아 팔 굵기에 맞추는 방식**이다. 11월 12일 위팔 260mm·아래팔 250mm를 받아 [배치도 초안](docs/ARM_LAYOUT_2026-11-12.svg)에 반영했다. 다음 작업은 착용 공간을 대조하고 모터·커프 위치와 제작 치수를 정하는 것이다. DOGCOM 기준 구매계획 소계는 490,967원이며 가공·추가 배선·보호부품·배송 등의 견적이 남아 있다.

> 변경 후에는 `PROJECT_STATE.md`와 결정 이력을 갱신한다. 이 문서가 자동으로 새 채팅에 주입된다고 가정하지 말고 작업 전 GitHub의 최신 파일을 직접 확인한다.
