# ROBOT_CHOSUN

**Second Muscle**은 위팔 모터가 벨트를 통해 팔꿈치 축을 돌려 팔 굽힘을 돕는 로봇이다. 현재는 실제 크기의 프레임을 손으로 조립해 팔꿈치 위치와 찍찍이 길이를 확인하는 단계다.

## 3D 출력 견적 받기 · 2026년 11월 21일

[업체 전달용 ZIP 다운로드](docs/assembly/forearm_fit/팔꿈치로봇_일괄시험출력.zip?raw=true) · [부품 그림과 조립 순서](docs/assembly/forearm_fit/조립과_견적.md) · [출력 수량표](docs/assembly/forearm_fit/print/출력_수량표_견적요청.txt)

ZIP에 STL **9종**이 들어 있다. 위팔 받침 **U31만 2개**, 나머지는 각 1개로 **총 10개**다. PETG, 실제 크기 100% 기준으로 한 번에 견적을 받는다. 모터 앞 풀리와 움직이는 모터판도 포함되어 있다. 볼트·너트·와셔·패드·찍찍이는 조립 안내에서 따로 확인한다.

## 구조와 설계 기록

벨트가 팔꿈치 풀리를 돌리면 금속 축에 파인 홈의 키 두 개가 풀리와 아래팔 연결통에 회전을 전달한다. 연결통은 볼트 네 개로 아래팔 프레임에 고정한다. 이번 출력물에는 손으로 굽혀 볼 시험축이 들어간다. 동력을 전달할 금속 축·베어링 지지대의 가공 및 실물 검증은 후속 단계다. [팔꿈치가 돌아가는 그림](docs/assembly/joint_drive/팔꿈치축_연결원리.gif)
